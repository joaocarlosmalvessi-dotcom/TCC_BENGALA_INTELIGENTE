# TCC — Bengala Inteligente

Arquivos do projeto de TCC da Bengala Inteligente.

Esta pasta está conectada ao repositório:
https://github.com/joaocarlosmalvessi-dotcom/TCC_BENGALA_INTELIGENTE

Adicione arquivos e subpastas nesta pasta para incluí-los no projeto.
O Git acompanha pastas que contêm arquivos; pastas vazias não são enviadas.

A sincronização automática é verificada pelo Codex a cada 10 minutos.
Mantenha o computador ligado, conectado à internet e o Codex aberto.
Alterações e exclusões locais também são enviadas ao GitHub.
Arquivos abrangidos pelo .gitignore não são enviados.
